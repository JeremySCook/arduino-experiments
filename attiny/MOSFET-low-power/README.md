Example code for Tiny Power 85 low-power MOSFET board.

Board is 22 x 22 mm:

![image](https://github.com/JeremySCook/JC-Pro-Macro-2/blob/main/documentation/images/JCPM2.jpg)

ac-watering - intermittently rotates a servo back and forth to modify water drainage path  
MOSFET-snore - turns MOSFET off intermittently

Examples require [TinySnore by Connor Nishijima](https://github.com/connornishijima/TinySnore)
