Experiments with Arduino Modulino boards using the UNO Q.  
Code available includes:

* modulino-distance-matrix.zip - Output from distance sensor on matrix + serial
* modulino-movement-matrix.zip - Stats in serial monitor + "y" accel on matrix
* modulino-RSC-pitch-roll.zip - Computes pitch/roll from accel values as positioned on  
robot servo chassis (RSC), prints to serial
* modulino-buzzer.zip - beeps 1 second on, 1 second off
* robot feedback (WIP)
